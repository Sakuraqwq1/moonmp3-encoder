# 决策记录

记录会影响后续实现方向的固定决策，避免阶段推进时反复推翻。

## D001：v1 只做 MPEG-1 Layer III、44.1 kHz、CBR 128 kbps、长块

- 状态：已采纳。
- 理由：范围可控，帧结构已稳定；短块、联合立体声、VBR 会显著扩大测试面。
- 影响：新增这些能力属于 v2 议题，不在阶段 1/2 顺手加入。

## D002：不使用心理声学模型，质量判据用固定 SNR

- 状态：已采纳。
- 理由：心理声学模型工程量大且难以客观验证；固定 SNR 能形成可复现的工程门槛。
- 影响：README 和申报书必须明确“不是 LAME 音质对标”，阶段 2 的正弦 ≥20 dB、音乐 ≥15 dB 是工程判据。

## D003：不读取、不移植 LAME/shine

- 状态：已采纳，红线。
- 理由：两者为 LGPL；验收要求许可证干净。
- 影响：算法依据 ISO/IEC 11172-3；Huffman 表使用 CC0 的 minimp3 数据并记录来源。详见 `docs/provenance.md`。

## D004：阶段 1 先关闭 bit reservoir

- 状态：建议采纳。
- 理由：跨帧状态会让单帧错误难以定位；先保证每帧 `main_data_begin = 0` 自洽，再开复用。
- 影响：阶段 1 的输出仍可解码，但压缩效率不是目标；reservoir 的连续性测试放到阶段 2。

## D005：0.1.x 是结构里程碑，不用于初审

- 状态：已采纳。
- 理由：只能输出可解码静音，核心功能不成立。
- 影响：真实音频链路通过阶段 1 判据后再评估初审；0.1.x 的包名和仓库只用于占位与发布流程验证。
