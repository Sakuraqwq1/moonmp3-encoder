# 频线索引与输出频率的映射（实测）

阶段 1 第 0 步的产出：一把在调试"能出声但频率不对"时用来定位问题的尺子。
这张表不是推导出来的，是**测出来的**；生成命令与数据都在文末。

## 1. 结论

128 kbps / 44100 Hz 的一个 granule 有 576 条频率线，按**子带优先**排列：

```text
line k  ->  subband = k / 18,  bin = k % 18
subband 宽度 = 44100 / 64 = 689.0625 Hz
每个子带 18 条长块 bin，line 间隔 = 44100 / 1152 = 38.28125 Hz
```

因此"这条线对应多少赫兹"只有一个数字要记：

**`f(line) = (line + 0.5) × 38.28125 Hz` 是 bin 中心；用在实信号上时，`line ≈ f / 38.28125`，精度不超过一行（±38.28 Hz）。**

## 2. 为什么之前 line 11 和 line 12 都测出 459 Hz

这不是测量误差，也不是解码器的问题，而是**探针信号本身**的退化。

`tone` 命令在每一帧、每个 granule 里都写入同一组 576 条系数。采样率 44100 Hz、
子带采样率 1378.125 Hz，一个 granule 的 36 个 子带样本、hop 18，所以重复同一个
频谱会让子带信号变成周期为 18（或 18 的因子）的周期信号。周期 18 的信号在子带
采样率下的谐波间隔是 `1378.125 / 18 = 76.5625 Hz`，也就是**只有 38.28125 的偶数倍
能出现**，奇数 bin 根本不可探。

于是单线探针的实际落点是被"向上取到偶数线"的：

```text
line k  ->  2 * ceil(k / 2) * 38.28125 Hz
```

line 11 → 12 × 38.28125 = 459.375 Hz，line 12 → 459.375 Hz。两条线当然一样。

用相邻两条线同时激励（`tone 16 12,13 206 1`）也救不回来：输出峰仍然是
459.334 与 535.961 Hz，都在 76.5625 Hz 网格上。**这个探针能给上界，不能分辨奇数 bin。**

## 4. 用这把尺子检查真实 PCM 路径

真实 PCM 不是重复单线，子带信号不再退化，因此可以用完整频率分辨率检查。
`src/mp3/analysis.mbt` 接上之后，`sine` 命令生成的真实正弦在解码端的落点如下
（`moon run cmd/main -- sine 16 <freq> 50 1`，8192 点以上 FFT）：

| 输入 Hz | 解码主频 Hz | 偏差 Hz | 说明 |
| ---: | ------: | ------: | --- |
| 440 | 440.23 | +0.23 | 子带 0 |
| 900 | 899.61 | -0.39 | 子带 1，奇数子带 |
| 1000 | 989.84 | -10.16 | 子带 1，落在两条 bin 之间 |
| 1100 | 1121.09 | +21.09 | 子带 1 |
| 2000 | 1998.83 | -1.17 | 子带 2 |
| 3000 | 2999.61 | -0.39 | 子带 4 |
| 5000 | 5028.52 | +28.52 | 子带 7，奇数子带 |
| 8000 | 8000.78 | +0.78 | 子带 11，奇数子带 |

偏差全部在一条频线（38.28125 Hz）以内：这是当前 count1 量化（每线只有 ±1，重
建频率只能落在频线网格上）的固有分辨率，不是滤波器组或 MDCT 的误差。
作为对照，在修好奇数子带的频谱反转之前，同一组测试的 8000 Hz 会解码成 7847.66 Hz
（偏差 -152 Hz，约 4 条线），1000 Hz 会解码成 1077.34 Hz。

## 5. 复现

```bash
# 单线探针，含相邻线对；写出 JSON 与 Markdown 表
python tools/probe_lines.py --lines 0-35 --pairs \
    --json target/line-frequencies.json --markdown target/line-freq-table.md

# 真实 PCM 路径的频率检查
moon run cmd/main -- sine 16 8000 50 1    # 输出 base64，交给 tools/spectrum.py 或上面的脚本
```

`tools/probe_lines.py` 的退出码非 0 表示有线的实测值偏离粗网格模型超过峰值估计
的不确定度，可以直接当回归门禁用。

## 6. 已知限制

- 单线探针无法分辨奇数 bin（第 2 节），要分辨必须让频谱随 block 变化；真实 PCM
  路径（`sine`、`encode`）没有这个限制。
- 峰值估计的不确定度由 FFT 长度决定：16384 点时 ±1.346 Hz，8192 点时 ±2.69 Hz。
- 8 kHz 以上的偏差只做过抽样检查；高频处子带内频线更密，抗混叠余量更小。
